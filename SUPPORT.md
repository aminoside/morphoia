# Support

<!-- SPDX-License-Identifier: CC-BY-4.0 -->

Morphoia Engine is experimental research software. It is not a medical device,
diagnostic service, clinical decision system, or production support contract.

## Getting help

Use the public issue tracker for reproducible installation problems, defects,
documentation gaps, and feature proposals that contain no sensitive data.
Include:

- commit or tag;
- OS, architecture, compiler, Python, and relevant dependency versions;
- exact command and configuration;
- minimal redistributable input or a synthetic reproducer;
- expected and observed result;
- evidence status (`PASS`, `FAIL`, `BLOCKED`, `NOT_RUN`, or
  `NOT_APPLICABLE`);
- sanitized logs and output hashes.

Do not post secrets, patient data, personal data, proprietary models, restricted
datasets, or confidential logs. Use the security procedure in `SECURITY.md` for
vulnerabilities.

## Scope of support

The mandatory support target for the first technical pre-release is the exact
Linux x86-64 CPU profile published in its release notes. SALOME, MED, CUDA, HIP,
SYCL, Slurm, containers, EuroHPC, and third-party application connectors are
supported only when the compatibility matrix records an executed result for the
reported version and environment.

No response time, compatibility duration, clinical outcome, proprietary-format
fidelity, or data-recovery guarantee is offered.
